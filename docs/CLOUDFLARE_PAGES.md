# Cloudflare Pages — original REDLINE refinement

- Project: `wolco-original-redline`
- Repository: `kloudocean-kodex/wolco-original-redline`
- Production branch: `main`
- Build command: `npm run build`
- Output: `out`
- No environment secrets are needed.

The build derives exact film sizes and Function routes before exporting Next.js. Only the film route uses the range-streaming Function; pages, images, fonts and scripts remain static. The preview is noindex. Git pushes to main trigger independent deployments. The existing `wolco-rebirth` and `wolco-atelier-demo` projects remain unchanged.

This is a client-review demo. No custom domain, original WordPress site or DNS cutover is included. Production launch requires approved business content, commercial details, media rights, lead delivery and domain/SEO checks.
